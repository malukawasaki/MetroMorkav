# MetroMorkav
This notebook models time-dependent mobility using origin–destination (OD) metro data and Morkav chains.

## Input
The model takes as input OD of public transport journeys in London during the month of January 2018. The data is available as .xlsx and is publicly avauilable at https://data.london.gov.uk/dataset/origin-and-destination-of-public-transport-journeys-204ok/.
